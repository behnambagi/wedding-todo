# 💍 پلنر هوشمند عروسی (Astro + Tailwind CSS)

پروژه برنامه‌ریزی جامع و زمان‌بندی روز عروسی (۴ آذر ۱۴۰۵) تفکیک‌شده به صورت کامپوننت‌های ماژولار در استرو (**Astro**) به همراه ذخیره‌سازی وضعیت در **کوکی‌های مرورگر (Browser Cookies)**.

## 🚀 ویژگی‌ها
- **تفکیک کامل ماژولار**: بخش‌های هدر، فیلتر، بنر هوشمند، تسک‌ها، تایم‌لاین ساعتی و مودال‌ها به کامپوننت‌های مستقل Astro تقسیم شده‌اند.
- **ذخیره در کوکی مرورگر (Cookie Storage)**: تمام تیک‌ها، اضافه کردن کارهای جدید، ویرایش‌ها و حذف به طور خودکار در کوکی مرورگر کاربر ذخیره می‌شوند و پایدار می‌مانند.
- **روزشمار زنده و درصد پیشرفت**: محاسبه روز، ساعت و دقیقه باقی‌مانده تا مراسم و محاسبه آنی پیشرفت تسک‌ها.
- **تایم‌لاین ساعتی روز عروسی**: دسته‌بندی ساعت به ساعت از بیدارباش صبح تا اتمام مراسم.
- **پشتیبانی از حالت چاپ (Print Ready)**: استایل بهینه برای چاپ کاغذی یا خروجی PDF تمیز.

## 🛠 راه‌اندازی پروژه

```bash
# نصب پکیج‌ها (قبلاً انجام شده است)
npm install

# اجرای سرور توسعه (Local Dev)
npm run dev

# خروجی نهایی بیلد
npm run build
```
